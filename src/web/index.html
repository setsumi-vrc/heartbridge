OBS overlay

Your pulse as a browser source, with a transparent background. Pick a look, copy the link and paste it into OBS.

  1. In OBS, Sources → + → Browser.
  2. Paste the link into URL. Width 600, height 300 fits every size up to 128.
  3. Leave Custom CSS as it is: the background is already transparent.

Build your own

Anything that speaks HTTP or WebSocket can read your pulse here: a bot, a game, smart lights, your own overlay. Every address below accepts requests from any origin.

ws://…/wsLive stream. A state message on every change and every 2 seconds, and a beat message on each heartbeat.
/eventsThe same stream as Server-Sent Events, for EventSource or curl.
/api/stateThe current state, once, as JSON.
/overlayThe OBS overlay above, with its options in the address.
